LMS as the name suggest is a learning management system which allows contributors to add contents to the learning path whcih after being approved gets assigned to students to get the knowledge.

🚀 Getting Started
Follow these instructions to get a copy of the project up and running on your local machine.

Prerequisites
You need to have Node.js installed on your computer. (Recommended: version 18).

🛠️ Installation
Clone the repository (if using Git): git clone https://github.com cd your-repo-name

Install the dependencies: npm install

💻 Usage
To start the project in development mode, run: npm start

Following is an .env.example for reference
JWT_SECRET=your_secret_jwt_token
DATABASE_URL="PostgreSQL://username:yourpassword@localhost:portNo/dbName?schema=public"
